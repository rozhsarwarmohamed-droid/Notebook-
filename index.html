Lesson 2.2

Comparative Adjectives

Exam revision notes

The big idea

Comparative → compares 2 things

adj + -er + than

The Thar Desert is smaller than the Sahara Desert.

How to make the comparative

1Short adjectives (1 syllable)

adj + -er (+ than)

small → smaller

2Ending in -e

Add only -r

wide → wider

3C-V-C spelling (big, hot, fat, thin)

Double the last consonant, then add -er

big → bigger

4Ending in -y (incl. 2-syllable -ly)

y → i + -er

dry → drier

friendly → friendlier

5Other adjectives with 2+ syllables

more + adj + than

dangerous → more dangerous

6Irregular: memorise!

good → better

bad → worse

far → farther / further

many / much → more

Exam focus

⚠️ Watch Out!

  • Irregulars are exam favourites: good → better (✗ gooder), bad → worse (✗ badder)
  • No double-ups: ✗ more bigger, ✗ more better → ✓ bigger, ✓ better
  • Spelling traps:
    • -e → just -r (✗ wideer)
    • C-V-C → double (✗ biger)
    • -y → -ier (✗ friendlyer)
  • than, not then: comparative + than (✗ then)
